# 지원 정책 v1 (초안)

계약 담당자, 운영 관리자를 위한 지원 정책 문서 — **초안**. `[결정 필요]` 표기 항목은 사업
정책 확정 후 채운다. 권장 기본값을 함께 제시한다.

---

## 1. 지원 범위

### 포함

- 제품 구성요소(RAG API, Enterprise 레이어, 관리 콘솔, 제공 배포 매니페스트)의 결함 수정
- 설치·업그레이드·설정에 대한 기술 문의
- 공식 문서([설치 가이드](../install/02-quickstart.md), [운영 runbook](../operations/01-runbook-k8s.md)) 기준 운영 이슈 지원
- 보안 취약점 패치

### 제외 (별도 계약 대상)

- 고객 인프라(Kubernetes, PostgreSQL, Redis, S3, IdP, GPU 서버) 자체의 운영·장애
- 임베딩·리랭킹 등 외부 AI 서비스(Ollama 모델, OpenAI, Jina)의 품질·장애
- 커스텀 개발(전용 커넥터, 응답 형식 변경 등), 데이터 마이그레이션 대행
- 공식 문서를 벗어난 구성(지원되지 않는 실행 모드, 임의 포크)에서 발생한 문제

## 2. 심각도 정의 및 응답 목표

| 심각도 | 정의 | 최초 응답 목표 | 해결 활동 |
|--------|------|----------------|-----------|
| S1 (긴급) | 서비스 전면 중단 또는 데이터 유실 진행 중, 우회 수단 없음 | [결정 필요] 권장: 영업시간 4시간 | 해결 시까지 연속 대응 |
| S2 (높음) | 핵심 기능(검색·인제스트·인증) 장애, 제한적 우회 가능 | [결정 필요] 권장: 1영업일 | 패치 또는 우회 방안 제시 |
| S3 (보통) | 일부 기능 이상, 운영 우회 가능 | [결정 필요] 권장: 3영업일 | 차기 정기 릴리스 반영 |
| S4 (낮음) | 문의, 개선 요청, 문서 오류 | [결정 필요] 권장: 5영업일 | 로드맵 검토 |

- 응답 목표는 "최초 응답"(접수 확인 + 초기 분석) 기준이며 해결 시한 보증(SLA)이 아니다.
  해결 시한 보증은 [결정 필요 — Enterprise 계약 옵션으로 제공 여부].
- 지원 시간대: [결정 필요] 권장: 영업일 09:00~18:00 KST (S1은 계약 옵션으로 연장).

### 접수 시 포함 정보

- 제품 버전(컴포넌트별), 배포 형태(docker-compose/k8s), 실행 모드(Dagster/경량)
- 증상, 재현 절차, 발생 시각
- `/ready` 응답, 관련 컨테이너 로그, (인제스트 문제 시) 문서 상태·`last_error`

## 4. 버전 지원 주기

- 버전 체계: `MAJOR.MINOR.PATCH` (semver). 컴포넌트(rag-api / rag-ent-api / rag-admin)는
  릴리스 단위로 호환 조합이 고지된다.
- 지원 대상: [결정 필요] 권장: **최신 MINOR + 직전 MINOR** (그 이전 버전은 최신으로
  업그레이드 후 지원).
- 보안 패치: 지원 대상 버전에 한해 제공.
- 지원 종료(EOL): [결정 필요] 권장: 종료 최소 6개월 전 고지.

## 5. 릴리스 채널

- 정기 릴리스: [결정 필요] 권장: 분기 1회 MINOR, 수시 PATCH.
- 릴리스 노트: 변경 사항, 호환성, 마이그레이션 절차 포함 — [02-releases.md](02-releases.md).
- 업그레이드 절차: [01-runbook-k8s.md §4](../operations/01-runbook-k8s.md) 참조.
