# 핵심 기능

RAG Platform의 핵심 기능을 지식베이스 관리, 문서 수집, 인덱싱, 검색, 접근제어, 통합
인터페이스, 관리 콘솔, 운영 지원 8개 영역으로 요약한다. 영역별 전체 기능·파라미터 목록은
[기능 카탈로그](../reference/04-features-catalog.md)를 참고한다.

표기: [Core] = 기본 배포부터 제공, [ENT] = Enterprise 배포에서 제공.

---

## 1. 지식베이스(KB) 관리 [Core]

목적별 KB를 개수 제한 없이 생성·운영하고, KB별 문서 상태(대기/처리 중/완료/실패)를
단일 호출로 집계해 확인한다. 삭제 시 벡터·원본 파일·메타데이터를 일괄 정리한다.

## 2. 문서 수집

파일 직접 업로드(PDF, Word, 한글(HWP), 텍스트, 마크다운, HTML 등)와 웹 크롤러·Confluence·
GitHub 커넥터를 통한 자동 수집을 모두 지원한다 [Core]. 커넥터는 증분 동기화, cron 스케줄,
실패 원인 가시성을 기본 제공한다. Enterprise 배포에서는 이미지 캡셔닝·스캔 문서 OCR·PDF
표 구조 보존 파싱 같은 고급 문서 이해 기능을 KB별로 켜고 끌 수 있다 [ENT].

## 3. 인덱싱 파이프라인 [Core]

문서 1건 = 독립 실행 1건으로 격리 처리해 특정 문서 실패가 다른 문서에 영향을 주지 않는다.
병렬 인덱싱, 해시·유사도 기반 2단계 중복 감지(한국어 형태소 분석 포함), 실패 문서 개별
재시도, KB별 설정 오버라이드(청킹 전략·중복 감지 임계값 등)를 지원한다.

## 4. 검색 [Core]

의미(dense) + 키워드(sparse) 하이브리드 검색을 RRF로 병합하고, 복수 KB를 한 번에 검색해
단일 순위로 통합한다. Jina 리랭커로 상위 결과를 재정렬하며, API 장애 시 자동으로 기본
순위 폴백해 검색 자체는 항상 성공한다.

## 5. 접근제어 [ENT]

기업 SSO(OIDC)와 KB 단위 RBAC(viewer/editor/admin/owner)를 REST API·검색·MCP 전체에
일관 적용한다. 이메일 기반 멤버십 초대, 소유권 이전과 자동 승계, 공개 KB, IdP 그룹 기반
슈퍼관리자를 지원한다.

## 6. 통합 인터페이스

REST API(Swagger UI 내장), MCP 서버(검색·KB 조회 툴 노출), CLI를 제공한다 [Core].
Enterprise 배포에서는 MCP 경로에도 동일한 JWT 인증과 KB 권한 필터가 적용된다 [ENT].

## 7. 관리 콘솔 (rag-admin)

대시보드, KB/커넥터/문서 관리, 검색 콘솔을 단일 빌드로 제공한다. Enterprise 배포에서는
같은 빌드에서 멤버십 관리(Access Management) 화면과 KB별 설정 오버라이드 편집 화면이
추가로 활성화된다 [ENT].

## 8. 운영 지원 [Core]

liveness/readiness 헬스체크, Dagster 기반 파이프라인 운영 UI(실행 이력·실패 로그·센서
상태), OpenTelemetry 기반 분산 트레이싱을 제공한다. Dagster 모드(운영 권장)와 내장 워커
모드(경량 구성) 중 실행 방식을 선택할 수 있다.
